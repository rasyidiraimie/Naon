Taruh gambar hero di folder ini dengan nama file = nama hero huruf kecil tanpa spasi/simbol.

Contoh: `hayabusa.png`, `change.png` (Chang'e), `yisunshin.png` (Yi Sun-shin), `popolandkupa.png`, `xborg.png`, `luoyi.png`.

Rasio potret (mis. 400x1100) paling bagus untuk kartu pick. Kalau gambar tidak ada, overlay otomatis menampilkan kartu warna + inisial.
